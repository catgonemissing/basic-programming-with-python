## Operator: Assignment

| Assignment Operator | Syntax (Python) |
| ------------------- | :-------------: |
| Assign              |       `=`       |
| Add and assign      |      `+=`       |
| Subtract and assign |      `-=`       |
| Multiply and assign |      `*=`       |
| Divide and assign   |      `/=`       |

## Operator: Comparison

| Comparison Operator      | Syntax (Python) | Meaning                     |
| ------------------------ | :-------------: | --------------------------- |
| Greater than             |       `>`       | Left is larger than right   |
| Less than                |       `<`       | Left is smaller than right  |
| Equal to                 |      `==`       | Both values are the same    |
| Not equal to             |      `!=`       | Values are different        |
| Greater than or equal to |      `>=`       | Left is larger or the same  |
| Less than or equal to    |      `<=`       | Left is smaller or the same |

## Data Types

| Data Type  | Description                            | Example                        |
| ---------- | -------------------------------------- | ------------------------------ |
| Integer    | Whole number                           | `123`                          |
| Float      | Decimal number                         | `3.14`                         |
| String     | Text (wrapped in quotes)               | `"test 123"`                   |
| Boolean    | Logical value — True / False           | `True`                         |
| List       | Collection of values (square brackets) | `["apple", "manggo"]`          |
| Dictionary | Key-value pairs (curly braces)         | `{"name": "Alice", "age": 20}` |
